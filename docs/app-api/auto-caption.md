# Auto caption: moved

Auto captions now need a signed-in user and cost credits, and the app uploads WAV audio. The
full, current contract (sign-in, the price quote, the upload, polling, refunds and every error)
lives in [`docs/app-credits-api.md`](../app-credits-api.md), section "Auto captions (paid)".

This file used to describe the anonymous, free version, which no longer exists.
